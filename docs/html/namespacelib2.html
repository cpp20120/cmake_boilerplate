int lib2::sum_on_worker ( int first_number,
int second_number )

Add two integers on a new worker thread and wait for it to finish.

Parameters
first_numberFirst operand, copied into the worker.
second_numberSecond operand, copied into the worker.
Returns
The sum after the worker has been joined.
Precondition
The mathematical sum must be representable as an int.
Exceptions
std::system_errorIf thread creation or joining fails.
Note
This call blocks and creates a new std::jthread for each invocation. It demonstrates the library's public Threads dependency; it is not intended to accelerate integer addition. Overflow is not checked.
